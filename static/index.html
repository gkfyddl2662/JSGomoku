SERVINGAkagi-NG · Mortal API

Akagi-NG에는 Mortal 모델 파일을 넣지 않습니다. Akagi-NG의 Online/AkagiOT 서버 URL을 이 API 주소로 설정하면 3P는 /react_batch_3p, 4P는 /react_batch로 통신합니다. 서버는 각 mode의 best_mortal.pth를 읽고 승격 시 자동 재로딩하며, 필요하면 위 버튼으로 안전한 strict hot-reload를 즉시 요청할 수 있습니다.
